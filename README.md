# 🍲 Página de Receitas

Site simples desenvolvido para praticar e aplicar conceitos de **HTML** e **CSS**, exibindo receitas culinárias com imagens e formatação visual.

## 📖 Sobre o projeto

Este projeto foi criado como exercício prático de desenvolvimento web front-end, com foco em estruturação de páginas em HTML e estilização com CSS.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3

## 💻 Como visualizar

1. Clone este repositório ou baixe os arquivos
2. Abra o arquivo `index.html` no navegador
